# PGT-mt Atlas — правила проекта

- **Независимость.** Atlas — самостоятельная, постоянно обновляемая научная база данных. Он не является приложением к какой-либо отдельной публикации (в т. ч. к обзорам); не связывать идентичность проекта, названия разделов или режимы графиков с нумерацией рисунков/таблиц публикаций.
- **Создатель и куратор — только Ilya Mazunin** («Created and curated by Ilya Mazunin»). Других создателей или кураторов платформы не указывать.
- **Атрибуция обязательна.** У каждого значения — первичная публикация, её авторы, DOI/PMID и строка исходной таблицы. Авторство первичных исследований не удалять и не изменять.
- **Исходные данные не изменяются без проверки.** `data/*.xlsx` — только чтение (контроль: `data/SOURCE_MANIFEST.sha256`); расхождения помечаются, а не исправляются молча. Изменения данных — отдельным PR с меткой `data-change`.
- **Двуязычность EN/RU.** Любой текст интерфейса добавляется в оба словаря (`site/src/i18n/ru.ts` — эталон ключей, `en.ts`). Проверять обе языковые версии.
- **Не публиковать автоматически** медицинские сведения о пациентах и неопубликованные материалы. Сайт и репозиторий не публиковать без явного решения куратора.
- **Стек:** React + TypeScript + Vite (SSG), Plotly, Python ETL (`etl/`). Наблюдаемые данные и модельные расчёты разделены в данных, коде и интерфейсе.
- **Дизайн:** Scientific Sketchbook — единое оформление всех страниц: белая бумага, синие чернила `#1F3FB4` (`--sk-ink`), текст `#34406E` (`--sk-ink-2`), красный акцент `#D42A2F` (`--sk-red`) для патогенной мтДНК и активных элементов; шрифты Cormorant Garamond (заголовки), Source Serif 4 (научный текст), IBM Plex Sans (интерфейс и данные), Caveat (подписи к рисункам). Токены — в `site/src/styles.css` (семантические токены внутренних страниц выводятся из `--sk-*`), цвета графиков — `site/src/lib/theme.ts`. Отдельные цвета сохраняются только для смысловых различий: наблюдаемые данные, модельный расчёт, предупреждения, полосы графиков.
- **Процесс:** работа в отдельных ветках; перед объединением — проверка и согласование куратора. Перед PR: `cd etl && python -m pytest -q`; `cd site && npm run typecheck && npm test && npm run build && npm run e2e`.
