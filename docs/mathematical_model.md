# Сценарная модель ПГТ-мт × ПГТ-А

Версия модели: 2026-10-12. Научный набор не изменён: 2026-10-11,
исходная проверенная ревизия `8c3bdc241504cf9605bc341a2bdd642afb68b958`.
Автор и куратор Atlas — Ilya Mazunin. Авторство первичных данных принадлежит
указанным исследовательским группам.

## Цель и единица расчёта

Событие — хотя бы одна из **заданных N бластоцист** проходит выбранный
критерий гетероплазмии и имеет строгий эуплоидный результат ПГТ-А.
Это не вероятность беременности, живорождения или здоровья ребёнка.
Модель не прогнозирует число полученных ооцитов/бластоцист и не калибрована
для новой пациентки. N=0 даёт нулевую вероятность этого лабораторного события.

Обозначения: h — входная доля прохождения критерия H, e — входная доля E,
q — совместная вероятность, ρ — сценарная корреляция **бинарных совместных
исходов**. Все вероятности находятся в [0,1].

## Входные доли и происхождение

`site/src/model/observations.ts` рассчитывает h=k/n по существующим записям
`atlas.fig3`. Исходный JSON, Excel, нормализация и ETL не изменяются.
В режиме ≤ воспроизводятся прежние 14 числителей/знаменателей.
В режиме < точные граничные значения исключаются. Например, m.3243A>G:
≤30% = 52/87; <30% = 51/87.

Интервалы классифицируются по верхней границе. Пересечения границы
отмечаются, середина не импутируется. ND условно считается ниже порога;
неизвестный LOD не становится истинным молекулярным нулём. В опубликованном
наборе 187 записей из 12 публикаций, 64 явно обозначенные бластоцисты,
71 запись с неуточнённой стадией и 53 ND без известного LOD. Пропуск стадии
не означает отсутствие бластоцисты. Число публикаций не является числом
независимых семей.

e=.7/.5/.3 для возрастов 30/35/40 остаётся **сценарным**, не оценённым по
возрастным числителям и знаменателям. Volodyaev 2025 — контекст возрастной
зависимости, не источник трёх непосредственно измеренных точек.

VUS m.3250T>C явно помечен. Значение 8/8 не устанавливает ни вероятность 1,
ни клиническую безопасность варианта.

## Независимые испытания

Всегда q = h P(E|H). При независимости двух тестов в одной целевой популяции
используется q=he. При независимых одинаковых исходах эмбрионов:

\[
P(S_N\ge1)=1-(1-q)^N.
\]

Численно применяется `-expm1(N*log1p(-q))`, с обработкой q=1 и N=0.
Контроль h=41/87,e=.5 даёт .235632/.553412/.800559 при N=1/3/6.

## Бета-биномиальная чувствительность

При 0<ρ<1:

\[
Q\sim Beta(\alpha,\beta),\quad S_N|Q\sim Bin(N,Q),
\quad\alpha=q(1/\rho-1),\quad\beta=(1-q)(1/\rho-1),
\]
\[
P(S_N\ge1)=1-B(\alpha,\beta+N)/B(\alpha,\beta).
\]

На сайте выбираются ρ=0/.05/.1/.2/.4. **ρ не оценена по Atlas.**
При ρ=0 используется независимый предел. Функция также поддерживает
предел ρ=1: P(≥1)=q для N≥1. Вычисление использует сумму логарифмов
отношений beta-функций, без переполнения при ρ→0.

Для h=41/87,e=.5,N=6 сценарии дают .800559/.756432/.715787/.642662/.518920.
При общей Q и фиксированной средней неоднородность снижает P(≥1) по
неравенству Йенсена. Это утверждение относится к общей-Q смеси, не ко всем
возможным зависимостям. Попарная корреляция сама по себе не определяет
произвольное совместное распределение эмбрионов.

Если beta-распределена только вероятность H, то Q=eΘ_H — масштабированная
beta на [0,e], а не обычная beta на [0,1]. Этот отдельный подход не
подменяется приведённой моделью совместного Q и не реализован как fit.

## Условная неопределённость h

Для k/n вычисляется 95% Wilson-интервал при **условной iid-биномиальной
likelihood**. 41/87 даёт примерно [.369823,.575136]; 8/8 — [.675592,1].
Он не учитывает кластеризацию, отбор публикаций, измерительную ошибку,
различия стадий и методов. Его нельзя представлять как интервал для новой
клинической семьи.

Опциональные полосы преобразуют границы Wilson функцией выбранного сценария
при фиксированных e,ρ. Это чувствительность к входной доле. Особенно при
ρ>0 они не являются совместно оценённым доверительным интервалом для
зависимых эмбрионов. Вложенность критериев ≤18/≤30 в текущих долях сохраняется;
независимые posterior-выборки двух порогов не генерируются.

Байесовский вариант для будущего прототипа: Dirichlet по трём категориям
H≤18,18<H≤30,H>30 либо единая CDF. Для одного порога при заданной iid-модели
допустим Beta-постериор, но он не исправляет семейную кластеризацию.

## Границы зависимости двух тестов

\[
\max(0,h+e-1)\le q\le\min(h,e).
\]

Сайт показывает границы q для **одного** эмбриона, условно на входных h,e.
Это не доверительные интервалы. Их преобразование в вероятность ≥1
потребовало бы дополнительного определения зависимости между эмбрионами,
поэтому таблица не выдаёт их за полный интервал успеха цикла.

## Что требует новых данных

У текущей модели нет fitted возрастных, семейных и вариантных коэффициентов,
непрерывной модели болезни или live-birth модели. Формально fit простой
beta-binomial по нескольким группам возможен под сильной обменностью;
малый неоднородный пилот не обосновывает переносимую популяционную ρ.

Иерархическое развитие требует нескольких семей на вариант, повторных
полных циклов, индивидуальных H×A и диагностических отказов. При случайном
N нужно интегрировать совместное распределение N,Q; объединённая доля
взвешивает семьи размером эмбрионального пула и не равна автоматически
средней вероятности новой семьи.

Механистическое развитие: Кимура с массами в 0/1 либо beta-приближение Wilson
с измерительной ошибкой и цензурированием. Это разные распределения даже при
одинаковых моментах. В авторском JAGS-коде Wilson есть усечение; его влияние
при низком H требует проверки. Моментный параметр b не является ни физическим
числом копий, ни бинарной корреляцией ρ. Published fit не воспроизведён и не
интегрирован на сайт. Модели естественной репродукции требуют полного журнала
беременностей и времени наблюдения, а не одного числа детей.
