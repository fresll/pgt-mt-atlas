## Что подготовлено

- Все 22 арабские страницы: интерфейс, разделы для пациентов и специалистов, 6 учебных глав, источники, методы, данные, вклад в проект, биография.
- Литературный арабский, RTL; меню и боковая навигация справа. Направление числовых осей и координат сохранено.
- `ScientificText` изолирует HGVS, научные сокращения, DOI и числовые фрагменты с помощью `bdi`, без скрытых bidi-символов внутри данных.
- Локализованы оси, легенды, пояснения, подсказки и инструменты Plotly. Добавлено раскрытие графика с закрытием Escape и удержанием клавиатурного фокуса внутри диалога. В арабской версии плотные панели расположены последовательно для читаемости.
- 580 описательных переводов применяются только при отображении. Исходные научные записи и экспортируемые машинные идентификаторы не изменены. CSV/Excel остаются английскими, как в действующем выпуске; это явно указано на странице данных.
- Названия авторов, DOI, PMID, названия журналов и точные машинные коды сохраняются. Их латиница не является непереведённым словом интерфейса.

## Независимая языковая проверка

Выполнен один отдельный модельный проход другим агентом, с чтением арабских авторских текстов и национальных/университетских медицинских платформ. Источники и конкретные исправления: [arabic-independent-review.md](arabic-independent-review.md). Это не проверка человеком — носителем арабского или медицинским переводчиком. Редкие термины تغاير البلازمية и الأديم الظاهر المغذي остаются согласованными редакционными решениями с определениями, а не заявленной общеарабской нормой.

## Локальный запуск

```bash
cd site
VITE_ATLAS_PRIVATE_PREVIEW=1 VITE_ATLAS_ARABIC_REVIEW=1 VITE_ATLAS_ENGLISH_REVIEW=1 VITE_ATLAS_CHINESE_REVIEW=1 npm run build
npm run preview
```

Открыть `http://localhost:4173/pgt-mt-atlas/ar/`.
Арабские маршруты включаются только двумя флагами PRIVATE_PREVIEW и ARABIC_REVIEW. Публичного флага для арабского языка нет. В локальной сборке нет аналитики и индексации. Сборку не загружали на внешний сервер; ветку не отправляли на GitHub.

## Проверки

- TypeScript: пройдено.
- Unit-тесты: 94 пройдены, включая сохранность ключей, всех числовых значений UI и учебных глав, ссылок, цитат и молекулярных кодов; непубличность арабских маршрутов; арабское двойственное и множественное число.

- Специальный Chromium E2E: 2 сценария пройдены, с обходом всех 9 научных графиков: раскрытие, арабские подписи/инструменты, увеличение где оно разрешено исходной моделью, подсказки, сброс, закрытие Escape; мобильные страницы и переход RTL → LTR с сохранением URL.
- `site/scripts/audit-arabic.mjs`: все 22 маршрута, desktop 1600×1100, mobile 390×844; снимки нормального/увеличенного состояния, интерактивные состояния учебных схем, переключение на продвинутый текст.
