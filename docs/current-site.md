# Текущая рабочая версия Atlas

Основной сайт: https://fresll.github.io/pgt-mt-atlas/

Основная ветка и источник публикации GitHub Pages — `main`.
Опубликованы пять локализаций: `/ru/`, `/en/`, `/es/`, `/zh-Hans/`, `/ar/` (22 страницы на язык).

При начале работы получите актуальную `origin/main` и создайте от неё отдельную рабочую ветку. Старый checkout сам по себе не является текущей версией сайта.

Ветка `audit/v13-preview` сохранена для истории. Её автоматическая публикация отключена. Архивные отчёты с другими ветками и адресами описывают состояние на дату отчёта.

Перенос выполнен 27 октября 2026 года из опубликованной ревизии `a5c5b26aa9b5cdb56f409348035609976fdfc94f`, включая арабскую версию и исправления графиков. Научные данные, модель и интерфейс при переносе не изменялись.

Локальные проверки — из каталога `site`: `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e`. Полная публичная сборка и проверки языков определены в `.github/workflows/deploy-pages.yml`.
