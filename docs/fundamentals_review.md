# Fundamentals / Основы ПГТ-мт — заметки для проверки куратором

Раздел: `/<en|ru>/fundamentals/` (оглавление), шесть глав `/<en|ru>/fundamentals/<slug>/`, библиография `/<en|ru>/fundamentals/references/`.

- Тексты глав: `site/src/content/fundamentals/ru.ts` (эталон структуры) и `en.ts`; строки интерфейса и моделей — в `site/src/i18n/{ru,en}.ts` (`fundamentals.*`).
- Библиография: `site/src/content/fundamentals/references.ts` — 56 источников; у каждого DOI и способ проверки
  (`pubmed` — DOI найден в записи PubMed; `publisher` — DOI с издательского PDF из `references/`; `preprint`).
- Иллюстрации: `site/scripts/sketch/generate.mjs` → `cell.svg`, `blastocyst-biopsy.svg`, `development.svg`, `fundamentals.json` (геометрия интерактивных схем). Прежние SVG при генерации не меняются.
- Модель бутылочного горлышка: `site/src/model/bottleneck.ts` (K ~ Bin(N, h₀)), тесты — `bottleneck.test.ts`.
- Проверки содержания: `site/src/content/fundamentals/fundamentals.test.ts` (совпадение структуры и ссылок RU/EN, существование источников и внутренних ссылок, объём глав, отсутствие привязки к отдельной публикации).

## Вопросы, требующие подтверждения автора

1. **Floros et al., 2018.** В главах приведено только то, что есть в аннотации (резкое снижение содержания мтДНК в первичных половых клетках, ~5 молекул на митохондрию). Средние копийности (≈1446 копий на ПГК CS12; 1,22×10⁶ в ооцитах) взяты в рукописи из полного текста, PDF которого нет в `references/`, — в Atlas не включены до сверки.
2. **Volodyaev et al., 2025 (F S Rev).** DOI 10.1016/j.xfnr.2024.100082 подтверждён по PDF издателя, но запись в PubMed не найдена.
3. **Franco et al., 2026** — препринт bioRxiv (DOI 10.64898/2025.12.31.697248), помечен как не прошедший рецензирование.
4. **Pickett et al., 2019.** В списке литературы рукописи инициалы указаны как «Pickett SH»; по PDF и PubMed — Sarah J. Pickett (SJ). В Atlas использовано SJ.
5. **Комплекс II и гены вариантов** (MT-TL1, MT-TK, MT-ATP6, MT-ND1, MT-ND3, MT-ND6) — общепринятые сведения; ссылка дана на обзор Gorman et al., 2016. Просьба подтвердить достаточность.
6. **Burr & Chinnery, 2024** использован для утверждения об экспоненциальном снижении m.3243A>G в крови с возрастом (по тексту обзора, ссылка [38] в нём); первичная работа отдельно не цитируется.
7. **Steffann et al., 2014 (Cell Rep)** цитируется для случая m.8344A>G (~50–60% у эмбриона и ребёнка), как в рукописи; просьба подтвердить соответствие.
8. **Ориентир 15–30%** для m.3243A>G приведён по Ji et al., 2023, как в рукописи.
9. Время статических `<title>`: заголовки страниц обновляются в браузере; в статическом HTML остаётся «PGT-mt Atlas» — так же, как на остальных страницах сайта.
