# Журнал происхождения данных и зависимых пересчётов

*PGT-mt Atlas. Created and curated by Ilya Mazunin.* Журнал ведётся с раунда 1 рецензии (2026-10-11).
Научную приёмку каждой записи выполняет куратор; Claude фиксирует источник, локатор и выполненные проверки.

## Принципы

- `data/Сопроводительная информация.xlsx` — зафиксированная историческая версия (SHA-256 `6ef93fd0…ecea`, `data/SOURCE_MANIFEST.sha256`). Она не изменяется.
- Корректировки вносятся отдельным слоем `etl/atlas_etl/curation/corrections.yaml`. ETL применяет его поверх значений xlsx и сохраняет исходное значение рядом (`value_source` / `fraction_source` в `atlas.json`; `value_source_pct`, `fraction_source`, `correction_ids` в `measurement.csv`). Перед применением ETL проверяет, что в xlsx стоит ожидаемое исходное значение; если оно изменилось, сборка останавливается.
- Все зависимые статистики пересчитываются ETL из исправленного набора. Те же статистики по исходной версии сохраняются в `stats.fig4_source_xlsx`, чтобы пересчёт был виден.
- Версии набора описаны в `etl/atlas_etl/curation/releases.yaml`: исходная зафиксированная версия `2026-10-10` и список изменений после неё.
- Идентификаторы записей хранятся в реестре `etl/atlas_etl/curation/record_ids.yaml` (см. раздел «Идентификаторы»).

## Идентификаторы (B2)

- Прежние идентификаторы зависели от номера строки xlsx: `f3-<строка>`, `f4-<строка>`, `cl-<строка>-b1/b2`.
- Новые: `HL-<публикация>-NNN` (распределение гетероплазмии), `EC-<публикация>-NNN` (фракции бластоцист), `CL-<публикация>-NNN` (стадия дробления). Выдаются один раз и хранятся в `record_ids.yaml` с отпечатком записи из источника (публикация, вариант, значение, стадия и материал как в источнике). Номер строки в отпечаток не входит.
- Прежний идентификатор сохранён в поле `legacy` / `legacy_id` и в `measurement.csv`; поиск на странице «Данные» и адрес `…/science/data/?id=f3-183` находят запись по прежнему ID.
- Новая или изменённая запись без ID останавливает обычную сборку. После проверки куратора: `python -m atlas_etl.build --assign-ids` (существующие ID не меняются, выбывшие получают `retired` и не переиспользуются).
- Родственные связи (эмбрионы одной пациентки, циклы) не вводились: в источнике их нет в явном виде.

## Проверка DOI и PMID (2026-10-11)

Для 20 из 22 публикаций набора DOI из списка литературы обзора однозначно сопоставлен с записью PubMed. PMID внесены в `publications.yaml` (`verified`). Исключения:
- **Volodyaev et al., 2025** (F S Rev 6:100082, doi:10.1016/j.xfnr.2024.100082): в PubMed нет; DOI подтверждён по PDF издателя.
- **Thorburn et al., 2009**: тезисы конференции, DOI нет и не подбирался; исключение зарегистрировано (`doi_exception`). Значения взяты из обзоров.

Найдено расхождение внутри источника: **Spath et al., 2021** (PMID 33745725) называет вариант пациентки C «m.10191T>G» в абстракте и введении, но «m.10191T>C» в результатах, подписи к рисунку и обсуждении (5 мест). Набор следует основному тексту; значения не менялись.
