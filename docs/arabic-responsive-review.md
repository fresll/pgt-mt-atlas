## Проверки

- `npm run typecheck` и закрытая сборка `VITE_ATLAS_PRIVATE_PREVIEW=1 VITE_ATLAS_ARABIC_REVIEW=1 VITE_ATLAS_ENGLISH_REVIEW=1 VITE_ATLAS_CHINESE_REVIEW=1 npm run build` — успешно.
- `npm test` — 94 успешно.
- Chromium: `npx playwright test --config playwright.arabic.config.ts` — базовые сценарии прошли; отдельный тест измерил пересечения текста X и отсутствие горизонтального переполнения страницы для четырёх научных маршрутов на 320×568, 375×667, 390×844, 430×932, 667×375, 844×390, 932×430, 768×1024, 1440×900. Вкладки модели проверены дополнительно.
- Отдельный сценарий раскрытия в 390×844 и 844×390: прокрутка клавиатурой там, где она необходима; данные `x`, `y`, `customdata` и диапазоны осей до/после раскрытия совпадают. Проверены все видимые научные панели.
- Учебные SVG-схемы и ползунки проверены в 320×568, 390×844, 844×390 и 1440×900.
- Снимки текущего состояния: `artifacts/arabic-responsive/`; снимки предыдущей проверки: `artifacts/arabic/`. Некоторые снимки показывают начальную видимую часть прокручиваемого графика; остальные подписи доступны при прокрутке.
- Тестов настоящего iPhone/Safari или WebKit не проводилось. Остальные языки в этой задаче не тестировались; их ранее опубликованное состояние не изменялось.
