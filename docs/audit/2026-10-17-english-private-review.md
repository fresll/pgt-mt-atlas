# Английская версия: закрытая проверка куратора

Куратор запросил ссылку на английскую версию перед её публичным открытием.
В обычной сборке адреса /en/ по-прежнему перенаправляются на /ru/.

Только для существующего проекта Sites с подтверждённым доступом владельца:

```sh
ATLAS_BASE=/ ATLAS_SOFT_LAUNCH=0 ATLAS_PUBLIC_LAUNCH=0 VITE_ATLAS_PRIVATE_PREVIEW=1 VITE_ATLAS_ENGLISH_REVIEW=1 npm run build
```

Оба флага VITE обязательны: один флаг английского режима не открывает язык
в публичной сборке. Закрытая сборка сохраняет noindex, отключает аналитику
и не создаёт sitemap. Авторизация обеспечивается настройкой доступа Sites,
а не этими флагами. Права доступа проверяются перед закрытой публикацией.

Используются существующие английские тексты. Перевод, научные данные,
математическая модель и оформление не меняются. Публичный GitHub Pages
не обновляется этим коммитом: [skip ci] оставляет опубликованную ревизию
8d650718761ff6a82fa3dc29f2cd784f4100e8ee. Проверки выполняются в облаке.
Публичное открытие английского языка требует отдельного разрешения куратора.
