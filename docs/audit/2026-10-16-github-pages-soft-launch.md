# GitHub Pages: публичный доступ без поисковой индексации

Куратор разрешил использовать существующий репозиторий `fresll/pgt-mt-atlas`
и адрес `https://fresll.github.io/pgt-mt-atlas/`.
Русская версия: `https://fresll.github.io/pgt-mt-atlas/ru/`.

## Источник и проверки

Публикуется только `audit/v13-preview`. Изменения в `main` и
`model/uncertainty-2026-10-12` не требуются. Workflow
`.github/workflows/deploy-pages.yml` запускается при push в эту ветку.
Перед публикацией он проверяет ETL, Python-тесты, TypeScript, unit tests,
обычную production-сборку и e2e, затем отдельно собирает артефакт Pages:

```sh
ATLAS_BASE=/pgt-mt-atlas/ ATLAS_SOFT_LAUNCH=1 ATLAS_PUBLIC_LAUNCH=0 VITE_ATLAS_PRIVATE_PREVIEW=0 npm run build
```

Перед загрузкой артефакта проверяются `noindex, follow` в каждом HTML,
разрешающий robots.txt и отсутствие sitemap. Счётчик включён.
Научные данные, дизайн и функциональность не изменяются.

## Однократная настройка владельцем

В Settings → Pages → Build and deployment выбрать Source: GitHub Actions.
Репозиторий переведён владельцем в публичный доступ; GitHub Pages доступен
бесплатно. Видимость репозитория и доступ к прежнему сайту Sites — разные
настройки: Sites остаётся доступен только владельцу.

Если окружение `github-pages` ограничивает ветки, разрешить deployment из
`audit/v13-preview`, сохранив прочие ограничения. Если требуется review
окружения, подтвердить конкретный запуск в GitHub Actions.

Если первый запуск не смог опубликовать из-за настроек Pages, после их
исправления повторить failed jobs в том же запуске. Готовность публикации
подтверждается успешным job `deploy` и проверкой реального URL без авторизации.
До этого новый URL нельзя объявлять работающим.

## Последующие изменения и индексация

Следующие коммиты в `audit/v13-preview` проходят тот же процесс и обновляют
тот же URL. Прежний сайт Sites не отключается этой конфигурацией.
Включение индексации требует отдельного разрешения куратора: только после
него изменить флаги сборки и задать правильный `ATLAS_CANONICAL_BASE`.
Sitemap в поисковые системы сейчас не отправлять.

Настройка исключения посещений GoatCounter хранится отдельно для каждого
домена. На новом домене её нужно включить повторно, если требуется:
`https://fresll.github.io/pgt-mt-atlas/ru/#toggle-goatcounter`.
