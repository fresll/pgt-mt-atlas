# Настройки поискового запуска (актуализировано 19 октября 2026)

Владелец явно разрешил индексировать обе языковые версии 19 октября 2026. Публичный адрес: `https://fresll.github.io/pgt-mt-atlas/`. Текущие изменения и проверки описаны в [отчёте запуска RU/EN](2026-10-19-bilingual-search-indexing.md).

Публичный workflow задаёт `ATLAS_PUBLIC_LAUNCH=1`, `ATLAS_SOFT_LAUNCH=0`, `ATLAS_CANONICAL_BASE=https://fresll.github.io/pgt-mt-atlas/`, `VITE_ATLAS_ENGLISH_PUBLIC=1` и отключает режим закрытого предпросмотра. Все 44 страницы RU/EN получают `index, follow`, собственные canonical и взаимные hreflang. Sitemap содержит обе версии; корневое перенаправление и 404 остаются `noindex`.

Без явного флага публичного запуска или при закрытом предпросмотре `noindex` сохраняется, sitemap не создаётся. Закрытый Sites не меняется. Статистика посещений публичного сайта сохраняется.

На сайте проекта GitHub Pages robots.txt в подпапке не управляет индексированием домена. Проверка деплоя дополнительно проверяет корневой robots.txt. Для непосредственной подачи sitemap в Google Search Console / Яндекс Вебмастер нужен доступ к соответствующему кабинету; такого подключения в текущем сеансе нет.
