# Чек-лист запуска (T-6; не активирован)

- [ ] Куратор принял научные тексты, данные и модель; четыре audit PR проверены.
- [ ] Выбран окончательный HTTPS-адрес с путём размещения.
- [ ] Для отдельной утверждённой сборки заданы `ATLAS_PUBLIC_LAUNCH=1` и `ATLAS_CANONICAL_BASE=https://домен/путь/`.
- [ ] Проверены canonical каждой RU-страницы, sitemap.xml и robots.txt на этом адресе.
- [ ] Проверены маршруты и пути GoatCounter после размещения.
- [ ] Публикация отдельно разрешена куратором.

По умолчанию флаг выключен, noindex сохраняется, sitemap и robots не создаются. EN остаётся перенаправлением с noindex; hreflang добавляется только после решения об открытии EN. Эта задача не включает деплой и не меняет CI.
