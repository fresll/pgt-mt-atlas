# Воспроизводимые расчёты математической экспертизы

Это исследовательские скрипты, сохранённые отдельно от рабочего ETL и данных
сайта. Они не обучают клиническую модель и не изменяют исходный Excel/Atlas.
Входной снимок относится к проверенной ревизии `8c3bdc2`, 2026-10-11;
`inputs/scenario.ts` сохраняет прежнее ядро для воспроизведения аудита.
Текущее расширенное ядро сайта находится в `site/src/model/scenario.ts`.

```sh
python3 analyze.py
python3 -m pip install -r review_requirements.txt
python3 independent_checks.py
node --experimental-strip-types verify_atlas.mjs
```

`analyze.py` использует стандартную библиотеку Python и содержит транскрипцию
проверенных первичных таблиц с публикацией/страницей/типом объекта. Он создаёт
154 строки наблюдений, 151 строку результатов, 11 известных циклов и отдельную
таблицу 35 эмбрионов с неустановленной принадлежностью циклу. Пропуск cycle_id
не образует общий цикл. Количество записей разных типов не становится числом
независимых эмбрионов. Выходы и технические загрузки исключены из Git.

`independent_checks.py` использует NumPy/SciPy: полиномы Якоби и адаптивную
квадратуру для независимой проверки Кимуры; интегрирование scaled-Beta;
проверку связности групп и примеры усечения авторского JAGS likelihood.
CDF при опубликованных округлённых моментах — сценарий, не повторный fit
82 ооцитов. Условные Fisher-тесты малых серий не доказывают независимость.

Авторская симуляция Wilson (нужен R):

```sh
python3 fetch_wilson.py
Rscript reproduce_wilson.R
```

Загрузчик получает неизменённые R/JAGS-файлы из `ijwilson/mtBottleneck`,
commit `1b6ea43ba9d179175db76c0c2ceebbdf16fd1845`. Seed=20261011.
Симуляция воспроизводится в R 4.5.0/4.5.1. Моментная диагностика отбора
не является клиническим JAGS fit; исходный клинический набор не получен,
MCMC и его калибровка не выполнены. Скачанный авторский код в Git не включён.

Математические определения и ограничения:
[спецификация модели](../../docs/mathematical_model.md),

NumPy 2.3.5, SciPy 1.17.0. Основной расчёт не имеет PyPI-зависимостей.
